    Hire Me — 5G Core Consulting & Training (Sydney, Australia)

    🚀 About Me

    I am a 5G Core engineer based in Sydney-Australia, specialising in hands‑on lab deployments, troubleshooting, and cloud‑based telecom environments.
    This website showcases practical 5G labs built using Open5GS, UERANSIM, AWS, Grafana, and Prometheus.

    If you need help building, understanding, or troubleshooting 5G Core systems, I offer consulting and training services.

    🛠 Services I Offer

    1. Build Your 5G Lab (Open5GS + UERANSIM)

    I design and deploy complete 5G labs for: - Universities
    - Startups
    - Research teams
    - IoT companies
    - Telecom engineers

    Deliverables include: - Fully deployed Open5GS Core
    - UERANSIM gNodeB + UE
    - AWS or on‑prem deployment
    - Custom scripts and automation
    - Troubleshooting documentation
    - Grafana dashboards for AMF/SMF/UPF KPIs

    I diagnose and fix issues such as: - Registration failures
    - PDU session problems
    - SBI / HTTP/2 errors
    - NRF discovery issues
    - SMF / UPF routing problems
    - GTP‑U traffic flow failures

    Hands‑on workshops for engineering teams: - 5G Core Architecture Deep Dive
    - Deploying Open5GS in Production‑like Environments
    - SBI / HTTP/2 Signalling Analysis
    - Grafana Observability

    4. 1:1 Training Sessions

    Personalised training for engineers who want to upskill quickly.

    Topics include: - Building a full 5G Core
    - Understanding AMF/SMF/UPF flows
    - Using UERANSIM effectively
    - AWS deployment
    - Grafana dashboards

    5. Custom Documentation & Lab Guides

    I create premium documentation packs: - Open5GS troubleshooting guide
    - UERANSIM deployment guide
    - 5G Core architecture diagrams
    - Grafana dashboard templates
